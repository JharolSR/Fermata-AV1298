# Fermata AV-1298 diagnostic variant

Target test setup:
- Samsung Galaxy S23 FE
- Android 16 / One UI 8.5
- Android Auto 17.6.663424
- Promaster AV-1298 Rev01 head unit
- Wired Android Auto

## Goal of v0.1

This branch does not attempt to bypass Android Auto safety or trust checks. Its purpose is to produce a separate Fermata test APK and capture enough diagnostics to determine whether Android Auto detects or rejects the package.

## Variant identifiers

- Base application ID: `me.aap.fermata.av1298`
- Auto suffix: `.av1298`
- Display name: `Fermata AV1298`
- Debug log tag: `FermataAV1298`

## Windows build

Requirements:
- JDK compatible with the project
- Android SDK / Android Studio
- `ANDROID_SDK_ROOT` configured

From the repository root:

```bat
tools\build-av1298.bat
```

The helper invokes the `autoDebug` variant with a distinct application ID so it can be tested independently from a normal Fermata installation.

## Install

After the APK is built, install it with ADB:

```bat
adb install -r path\to\the-built.apk
```

## Diagnostics

Enable USB debugging on the phone and verify:

```bat
adb devices
```

Then run:

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\diagnose-aa.ps1
```

The script clears logcat, asks you to connect Android Auto to the AV-1298, captures relevant entries and writes:

`tools/android-auto-av1298-log.txt`

Useful strings include:
- `FermataAV1298`
- `CAR.AUTH`
- `isPackageAllowed`
- `PlayGearhead`
- `Finsky`
- `fermata`

## What the startup diagnostics record

The AV-1298 branch logs:
- actual package name
- whether the Auto flavor is running
- Android version / API level
- manufacturer and model
- display pixel size
- density
- logical screen size in dp
- orientation

This helps separate three different problems:
1. the APK never starts;
2. Android Auto sees the package but rejects it;
3. the package is accepted but its projected UI has a rendering or compatibility issue.

## Safety scope

Testing video or mirroring features should be performed with the vehicle parked. This branch is not intended to disable motion restrictions or other driving-safety controls.
